# Запуск через USB (БЕЗ Wi-Fi)

## Шаг 1: Включи отладку по USB на телефоне

1. Настройки → О телефоне
2. Тапни 7 раз по "Номер сборки"
3. Появится "Вы стали разработчиком"
4. Назад → Для разработчиков
5. Включи "Отладка по USB"

## Шаг 2: Подключи телефон к компьютеру

1. Подключи USB кабель
2. На телефоне разреши отладку по USB (появится окно)

## Шаг 3: Проверь подключение

Открой терминал и введи:
```bash
adb devices
```

Должно показать твоё устройство.

## Шаг 4: Запусти Expo

```bash
npx expo start
```

Затем нажми клавишу `a` - приложение установится на телефон!

---

# Если ADB не найден

Установи Android Platform Tools:
https://developer.android.com/studio/releases/platform-tools

Или установи весь Android Studio.
