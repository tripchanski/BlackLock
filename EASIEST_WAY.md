# САМЫЙ ПРОСТОЙ СПОСОБ ЗАПУСТИТЬ

## Вариант А: Android Studio Эмулятор (30 минут, 100% работает)

### 1. Скачай Android Studio
https://developer.android.com/studio

### 2. Установи
- Запусти установщик
- Выбери всё по умолчанию
- Дождись установки SDK

### 3. Создай виртуальный телефон
1. Открой Android Studio
2. More Actions → Virtual Device Manager
3. Create Device
4. Выбери Pixel 5
5. Download → R (Android 11)
6. Finish
7. ▶ Launch (зелёная кнопка)

### 4. Запусти приложение
```bash
# В терминале BlackLock
npx expo run:android
```

ВСЁ! Приложение само соберётся и запустится на эмуляторе.

---

## Вариант Б: Expo Go через туннель (5 минут, если повезёт)

### 1. Остановить все запущенные серверы
В терминале нажми Ctrl+C несколько раз

### 2. Запустить с туннелем
```bash
npx expo start --tunnel
```

### 3. В Expo Go на телефоне
- Открой Expo Go
- Отсканируй QR из терминала
- ИЛИ введи вручную URL который покажется (начинается с exp://)

---

## Вариант В: Прямая установка APK (если есть Android Studio)

### 1. После установки Android Studio
```bash
# Собрать APK
npx expo run:android --variant release

# APK будет в:
# android/app/build/outputs/apk/release/app-release.apk
```

### 2. Перекинь APK на телефон и установи

**Вариант А** - самый надёжный. Android Studio + эмулятор = 100% работает.

Размер: ~1GB
Время: 30-40 минут установки

## Если хочешь БЫСТРО попробовать:

1. Закрой все терминалы с Expo
2. Открой новый терминал
3. Введи:
```bash
npx expo start --tunnel --clear
```
4. Подожди 1-2 минуты пока всё загрузится
5. Отсканируй QR в Expo Go

Если не работает - ставь Android Studio, это самый надёжный путь.
